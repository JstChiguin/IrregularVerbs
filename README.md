# 📚 IrregularVerbs

### Aprende y practica verbos irregulares mediante reproducción automática e interacción personalizada.

Aplicación web desarrollada para practicar los verbos irregulares del idioma inglés mediante reproducción automática, organización por grupos y herramientas que facilitan el aprendizaje.

---

# ✨ Características

- 🔊 Pronunciación mediante la Web Speech API.
- 🔁 Reproducción automática en modo bucle.
- 📂 Organización de verbos por grupos.
- ✅ Selección individual o múltiple de grupos.
- ☑️ Seleccionar todos los grupos con un solo clic.
- 🔇 Inclusión y exclusión de grupos completos del bucle.
- 🔇 Inclusión y exclusión individual de verbos.
- 💡 Notas gramaticales para verbos con usos especiales.
- 📱 Diseño adaptable para distintos tamaños de pantalla.
- 🔒 Integración con Wake Lock API para evitar que la pantalla se apague durante la reproducción (cuando el navegador lo permite).

---

# 🛠 Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla JavaScript)
- Web Speech API
- Wake Lock API

# ▶️ Cómo utilizar

1. Abrir la aplicación en un navegador compatible.
2. Seleccionar uno o más grupos de verbos.
3. Presionar **Comenzar**.
4. Configurar el modo de reproducción según las preferencias.
5. Utilizar los controles para incluir o excluir grupos y verbos durante la práctica.
